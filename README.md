# ☕ Ember & Oak — Coffee Shop Website

A modern, responsive coffee shop website concept built with HTML, CSS, and JavaScript.

🔗 **Live Website:** https://sayanft.github.io/ember-oak-website/

## 📖 About the Project

Ember & Oak is a fictional specialty coffee shop website designed to create a warm, welcoming, and premium online experience.

The project focuses on clean layouts, coffee-inspired visuals, simple navigation, and responsive design.

## ✨ Features

- Home page with a coffee shop introduction
- About page sharing the brand story
- Menu page showcasing coffee and other items
- Contact page with a demonstration contact form
- Responsive navigation for smaller screens
- Interactive menu filters
- Consistent styling across pages

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling and responsive layouts
- **JavaScript** — Interactive features and form validation

## 📂 Project Structure

```text
ember-oak-website/
├── index.html
├── about.html
├── menu.html
├── contact.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── images/
```

## 🚀 Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server, or open it directly in your browser.

## 📝 Important Note

This is a portfolio project created for learning and demonstration purposes. Ember & Oak is a fictional brand, and the contact form does not send real messages.
